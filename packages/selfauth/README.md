# selfauth

The short name for [`@selfauth/cli`](https://www.npmjs.com/package/@selfauth/cli):

```bash
npx selfauth init my-app --database postgresql --frontend vue
```

SelfAuth generates authentication code into your project. You own that code,
and nothing it generates depends on SelfAuth at runtime. See the
[repository](https://github.com/thetejasmagade/selfauth) for documentation.
