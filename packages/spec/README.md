# @selfauth/spec

The language-neutral SelfAuth specification, plus the tooling around it.

- `specs/*.md` are the normative documents: authentication, authorization,
  security requirements, data model, errors, configuration, conformance and
  optional capabilities. Requirements carry stable IDs such as
  `**[SEC-CSRF-004]** (MUST)`.
- `parseRequirements()` and `loadRequirements()` read those IDs, and
  `findRequirementReferences()` finds where they are cited.
- `selfAuthConfigSchema`, `parseConfig()`, `defineConfig()` and
  `configJsonSchema()` validate `selfauth.config` against the spec's bounds.
  For example, Argon2 settings below the
  OWASP floor are rejected, and so is an idle timeout longer than the
  absolute one.
- `ERROR_CODES`, `ERROR_HTTP_STATUS` and `isErrorCode()` cover the error
  envelope and its codes.

```ts
import { parseConfig, loadRequirements, SPEC_VERSION } from "@selfauth/spec";
```

Projects generated by SelfAuth don't depend on this package at runtime. They
keep a local copy of the types. See the
[repository](https://github.com/thetejasmagade/selfauth).
