# API reference

- [HTTP API](http.md): the `/auth` routes, bodies, responses, errors, CSRF
  and cookies.
- [Server API](server.md): `createAuth`, route guards, policies and the
  exports of the generated `auth/` module.
- [Client API](client.md): the generated frontend client and its Vue and
  React layers.
- CLI: [`packages/cli/README.md`](../../packages/cli/README.md), or
  `selfauth <command> --help`.
- Packages: [`@selfauth/spec`](../../packages/spec/README.md),
  [`@selfauth/migration`](../../packages/migration/README.md) and
  [`@selfauth/conformance`](../../conformance/README.md). These are
  development tools; generated apps don't import them.
