# Changelog

SelfAuth is `0.x`: minor versions may change generated code and behavior, and each change below says what to do. Security fixes ship as patch releases. See [`diff` and `upgrade`](/reference/cli/upgrade) for how to take a release.

The full history of every package is in the repository: [CLI](https://github.com/thetejasmagade/selfauth/blob/main/packages/cli/CHANGELOG.md), [spec](https://github.com/thetejasmagade/selfauth/blob/main/packages/spec/CHANGELOG.md) and [migration](https://github.com/thetejasmagade/selfauth/blob/main/packages/migration/CHANGELOG.md).
