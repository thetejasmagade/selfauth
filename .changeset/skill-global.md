`selfauth skill install --global` (or `-g`) installs the agent skill into your home folder (`~/.claude/skills/selfauth/`, `~/.agents/skills/selfauth/`, `~/.cursor/skills/selfauth/`), so every project has it. It can't be combined with a project folder; `--agent`, `--update` and `--dry-run` work as before.
